# Welcome to [Slidev](https://github.com/slidevjs/slidev)!

This Slidev project renders a simple Notes app UI on the main slide using an Ocean Professional theme (blue and amber accents, modern, rounded, subtle shadows). Notes are stored locally in your browser via localStorage.

How to run locally:

- `pnpm install`
- `pnpm dev`
- visit <http://localhost:3030> (or the port configured by Slidev)
- The app will also work on the existing environment at the configured Vite dev server port.

Features:

- Create, select, edit, and delete notes
- Changes persist across refresh via localStorage
- Accessible inputs with labels and focus states
- Floating + button for quick create
- Clean two-column layout (list + editor)

Edit the [slides.md](./slides.md) to see the changes.

Learn more about Slidev at the [documentation](https://sli.dev/).
